# نظرة عامة على المشروع / Project Overview

موقع ويب لحجز خدمات صالون نسائي بفرع واحد.
A web application for booking women's salon services — single branch.

## المستخدمون / Users
- **Customers** — العملاء: يتصفحون الخدمات ويحجزون.
- **Staff** — الموظفات: يقدّمن الخدمات ولهنّ ساعات عمل.
- **Admin / Receptionist** — الإدارة: تدير النظام بالكامل.

## ثوابت النظام / System constants
- اللغتان المدعومتان: العربية والإنجليزية.
- التوقيت: `Asia/Riyadh` لجميع التواريخ والأوقات.
- الواجهة Responsive بالكامل وتدعم RTL.
- جميع العمليات المهمة تُسجَّل في Audit Logs (Activity Log).

## نطاق المشروع / Scope
- فرع واحد فقط — لا يوجد دعم لفروع متعددة.
- العروض مدعومة بدون كوبونات.
- الإشعارات عبر البريد الإلكتروني (SMS اختياري مستقبلاً).
