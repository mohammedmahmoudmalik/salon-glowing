# قواعد العمل الكاملة / Business Rules

> هذا هو المرجع الأساسي. عند أي تعارض، هذا الملف يحكم.

## 1. قواعد عامة
- موقع ويب لحجز خدمات صالون نسائي، فرع واحد فقط.
- يدعم: العملاء، الموظفات، الإدارة.
- يعمل بالعربية والإنجليزية.
- جميع التواريخ والأوقات بتوقيت السعودية.
- النظام Responsive بالكامل.
- العمليات المهمة تُسجَّل في Audit Logs.

## 2. قواعد العملاء
### التسجيل
- التسجيل برقم الجوال أو البريد الإلكتروني.
- رقم الجوال يجب أن يكون فريداً.
- تسجيل الدخول بالجوال أو البريد الإلكتروني.

### الملف الشخصي
يمكن للعميلة تعديل: الاسم، الصورة الشخصية، الجوال، البريد، كلمة المرور.

### المزايا
استعراض الخدمات، استعراض الموظفات، إنشاء/تعديل/إلغاء الحجز،
مشاهدة الحجوزات السابقة، تقييم الخدمة والموظفة.

## 3. قواعد الحجز
### الإنشاء
اختيار: الخدمة، الموظفة، التاريخ، الوقت.

### قواعد التحقق
- لا يمكن حجز موعد محجوز مسبقاً.
- لا تستقبل الموظفة أكثر من حجز بنفس الوقت.
- لا حجز خارج ساعات العمل.
- احترام مدة الخدمة.
- إضافة Buffer Time بين الحجوزات (مثلاً 10 دقائق).

### الحالات
Pending → Confirmed → Completed | Cancelled | NoShow

### الإلغاء
- العميلة تلغي قبل الموعد بـ 3 ساعات على الأقل، ولا يُسمح بعد ذلك.
- الإدارة تلغي أي حجز في أي وقت.

### إعادة الجدولة
- مسموحة إذا كان الوقت الجديد متاحاً.
- لا تعديل بعد بدء الموعد.

## 4. قواعد الخدمات
### البنية
كل خدمة: الاسم، الوصف، السعر، المدة بالدقائق، صورة، الفئة، حالة التفعيل.

### الفئات
أمثلة: Hair, Makeup, Nails, Facial, Spa.

### التوفر
- يمكن تعطيل أي خدمة من لوحة الإدارة.
- الخدمات المعطلة لا تظهر للعملاء.

## 5. قواعد الموظفات
### المعلومات
كل موظفة: الاسم، الصورة، التخصص، وصف مختصر، ساعات العمل،
الخدمات المقدّمة، حالة النشاط.

### التوفر
لا تظهر الموظفة للحجز إذا: كانت غير نشطة، أو خارج ساعات العمل،
أو لديها حجز بنفس الوقت.

## 6. قواعد العروض
- النظام يدعم العروض فقط بدون كوبونات.
- كل عرض: عنوان، وصف، صورة، نسبة الخصم/السعر الجديد،
  تاريخ بداية، تاريخ نهاية، الخدمات المشمولة، حالة التفعيل.
- لا يظهر العرض إذا انتهت صلاحيته.
- العرض يُطبَّق تلقائياً على الخدمة.
- الإدارة تفعّل أو توقف العرض.

## 7. قواعد التقييمات
- التقييم بعد اكتمال الحجز فقط.
- تقييم واحد لكل حجز.
- التقييم من 1 إلى 5.
- الإدارة تحذف أو تخفي التقييمات المسيئة.

## 8. قواعد الإشعارات
تُرسل الإشعارات عند: إنشاء الحجز، تأكيده، إلغائه، التذكير بالموعد.
القنوات: Email (SMS اختياري مستقبلاً).

## 9. قواعد الإدارة
### لوحة التحكم تعرض
عدد الحجوزات، الحجوزات اليومية، الخدمات الأكثر طلباً،
تقييمات العملاء، أداء الموظفات، الإيرادات اليومية والشهرية.

### الأدوار
- **Admin**: صلاحية كاملة على جميع الصفحات.
- **Receptionist**: إدارة الحجوزات والخدمات والعملاء والعروض والتقييمات.
- **Owner**: يدخل للوحة التحكم مباشرةً على صفحة الإعدادات، ويتحكم فقط في **هوية الصالون** (الشعار، الاسم، الألوان) و**نصوص الصفحة الرئيسية** (Hero).

## 10. ساعات العمل
الإدارة تحدد أيام العمل وساعاته. لا حجز خارج هذه الأوقات.

## 11. قواعد الوسائط
رفع صور لـ: الخدمات، الموظفات، العروض.
الصيغ المسموحة: jpg, png, webp — مع حد أقصى للحجم.

## 12. قواعد الأمان
كلمات المرور مشفّرة، CSRF Protection، Validation لكل المدخلات،
منع SQL Injection، منع XSS، استخدام HTTPS.

## 13. المعمارية التقنية
- Backend: Laravel 12 + Sanctum + MySQL + REST API.
- Frontend: Blade + Livewire أو Next.js منفصل.
- النمط المفضل: Feature-Based + Service Layer + Form Requests + API Resources +
  Repository Pattern عند الحاجة فقط.

## 14. الجداول الأساسية
users, customers, staff, services, service_categories, bookings,
booking_items, offers, reviews, notifications, settings.

## 15. الصفحات الرئيسية
- العميل: Home, Services, Service Details, Staff, Booking, My Bookings, Profile, Login/Register.
- الإدارة: Dashboard, Services, Staff, Bookings, Offers, Reviews, Settings.

## 16. قواعد الـ API
RESTful APIs مع API Resources، Form Requests، Global Exception Handling،
Pagination، Validation، استجابات موحّدة.

## 17. الأداء
Pagination، Lazy Loading للصور، Eager Loading لتقليل الـ Queries، Caching عند الحاجة.

## 18. الواجهة والتجربة
النمط: Elegant, Feminine, Luxury, Minimal, Mobile-First.
الألوان: White, Beige, Rose Gold, Soft Pink.

## 19. قواعد التطوير مع Claude Code
بناء تدريجي، كود إنتاجي فقط، أفضل ممارسات Laravel، مكوّنات قابلة لإعادة الاستخدام،
بنية وحدات، تجنّب التعقيد، تسمية صحيحة، Policies & Gates، Validation لكل Request،
Controllers رفيعة، منطق العمل في Services/Actions.
