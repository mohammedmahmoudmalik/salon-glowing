# وحدة العروض / Offers Module

## القاعدة
عروض فقط — بدون كوبونات.

## بنية العرض
عنوان (ar/en)، وصف (ar/en)، صورة، نوع الخصم (نسبة/مبلغ ثابت)،
قيمة الخصم، تاريخ بداية، تاريخ نهاية، الخدمات المشمولة، حالة التفعيل.

## القواعد
- لا يظهر العرض إذا انتهت صلاحيته (`ends_at` مضى) أو كان غير مفعّل.
- العرض يُطبَّق تلقائياً على الخدمة المشمولة.
- الإدارة تفعّل/توقف العرض.
- إذا تداخل أكثر من عرض على نفس الخدمة: طبّق الأفضل للعميلة
  (أو حدّد قاعدة واحدة واضحة — اسأل قبل التنفيذ).

## الحساب
- نسبة: `final = price - (price * value / 100)`.
- مبلغ ثابت: `final = max(0, price - value)`.

## العلاقات
- `Offer` belongsToMany `Service`.

## ملفات متوقعة
- `StoreOfferRequest`, `UpdateOfferRequest`
- `Admin/OfferController`
- `OfferResource`
- `OfferPolicy`
- `ActiveOfferService` — يحسب العرض الساري لخدمة معيّنة.

## ملاحظات
- استخدم scope `active` يفحص التاريخ + حالة التفعيل.
- سعر الخدمة المعروض للعميلة يمر عبر `ActiveOfferService`.
