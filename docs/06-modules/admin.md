# وحدة لوحة الإدارة / Admin Module

## النطاق
لوحة تحكم الإدارة: الإحصائيات وإدارة كل وحدات النظام.

## الأدوار والصلاحيات
- `admin` — وصول كامل لكل شيء.
- `receptionist` — إدارة الحجوزات والعملاء والتقييمات، دون الإعدادات
  والصلاحيات الحساسة.
استخدم Policies & Gates لتطبيق الفرق بدقة.

## لوحة المعلومات / Dashboard
تعرض:
- عدد الحجوزات الإجمالي.
- الحجوزات اليومية (لليوم الحالي).
- الخدمات الأكثر طلباً.
- تقييمات العملاء (المتوسط وأحدثها).
- أداء الموظفات (عدد الحجوزات المكتملة + متوسط التقييم لكل موظفة).
- الإيرادات اليومية والشهرية.

### تعريف الإيرادات / Revenue definition
- الإيراد يُحتسب من الحجوزات بحالة `completed` فقط.
- القيمة المحتسبة هي `total_price` بعد تطبيق العروض.
- الحجوزات الملغاة أو no_show لا تدخل في الإيرادات.

## شاشات الإدارة
- إدارة الخدمات والفئات (إنشاء/تعديل/تفعيل/تعطيل).
- إدارة الموظفات وساعات عملهن (وإنشاء حساب الموظفة).
- إدارة الحجوزات (عرض/تأكيد/إكمال/إلغاء/no_show).
- إدارة العروض (إنشاء/تعديل/تفعيل/إيقاف).
- إدارة التقييمات (إخفاء/حذف المسيء).
- الإعدادات (ساعات عمل الصالون، Buffer الافتراضي).

## ملفات متوقعة
- `Admin/DashboardController`
- `DashboardStatsService` — يجمّع كل الإحصائيات.
- `Admin/SettingController`, `UpdateSettingsRequest`
- باقي شاشات الإدارة عبر `Admin/*Controller` الموجودة في وحداتها.

## ملاحظات
- استخدم Eager Loading و Caching للإحصائيات (لا تعيد الحساب في كل طلب).
- كل عمليات الإدارة تُسجَّل في Activity Log.
- مسارات الإدارة كلها تحت `/api/v1/admin` ومحمية بـ middleware للأدوار.
